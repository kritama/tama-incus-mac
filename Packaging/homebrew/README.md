# Homebrew release boundary

No formula is published yet: there is no release URL, immutable source checksum, signed/notarized binary or production appliance catalog. Do not ship a formula with placeholder checksums or notarization claims. A future formula should require macOS 15+ and Apple Silicon, install the entitled `macus` executable, provide an explicit per-user daemon service, and preserve state on uninstall. Local source installation until then is `Packaging/install-local.sh`, which requires Swift. Build/test commands are in docs/development.md. The Incus CLI is optional for users and required only by the interoperability acceptance script.
